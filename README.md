# MediaSpine — Landing Page

A modern, animated landing page for [MediaSpine](https://mediaspine.vercel.app) — a real-time clinical AI posture and facial biometric scanner built for the SpineSafe NGO Platform.

## 📁 Files

| File | Description |
|------|-------------|
| `index.html` | Main landing page (HTML + CSS + JS, all-in-one) |
| `mediaspine_hero.jpg` | Hero section illustration |

## 🚀 Usage

No build step needed — just open `index.html` in your browser, or deploy to any static host.

### Deploy to Vercel
1. Push this folder to a GitHub repository
2. Go to [vercel.com](https://vercel.com) → **New Project**
3. Import your repository
4. Click **Deploy** — done!

### Deploy to GitHub Pages
1. Push this folder to a GitHub repository
2. Go to **Settings → Pages**
3. Set source to `main` branch, `/ (root)`
4. Your site will be live at `https://<username>.github.io/<repo-name>`

## ✨ Features

- Dark glassmorphism design with animated ambient orbs
- Scroll-triggered fade-up animations
- Animated number counters
- Interactive step-by-step "How It Works" section
- Live terminal mockup
- Fully responsive layout
- Zero dependencies — pure HTML, CSS & Vanilla JS
